Everything in the box

A whole writing surface, not just bold and italics

Saving, uploads and search stay in your app; the editor brings the rest.

A minimap you can actually follow

Not a shrunk photo of grey blocks, but a spatial outline. Headings render as readable labels at their true position, body text becomes content-derived density, images show real thumbnails, and the whole document fits the panel so you always know where you are.

  • Click a heading to jump to it
  • Draggable viewport, fit to panel
  • Fully themeable via CSS variables

Focus mode, version history & a configurable toolbar

Dim everything but the sentence you're writing. Keep a client-side history stack with a visual/text/source diff and one-click restore. Let users rearrange the toolbar with a drag-and-drop customizer, or lock it down with presets.

  • Host-controlled width, font & dimming
  • Diff view with restore
  • Responsive toolbar collapses to “More”

Quick start

Two imports and a component

Own the editor instance with a hook; render it with one component. Everything else is props.

1. Install

# the package
npm install inscript-editor

# its peers (React + TipTap)
npm install react react-dom @tiptap/core \
  @tiptap/react @tiptap/starter-kit …

2. Use

import { useInscriptEditor, InscriptEditor }
  from 'inscript-editor';
import 'inscript-editor/styles';

function Post() {
  const api = useInscriptEditor({
    contentKey: filename,
    onContentChange: (e) => save(e),
  });
  return <InscriptEditor {...api} />;
}
